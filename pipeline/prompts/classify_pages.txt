You are classifying pages from an Australian residential architectural working drawing set.
The document is a CAD-exported PDF. Each page has a title block at the bottom or right edge
containing a drawing title, drawing number (e.g. A100, A201), scale, and date.

CLASSES (use exactly these strings):
  title_sheet                — cover / project info page
  general_notes              — written notes, specifications, legends
  site_plan                  — PROPOSED site plan with AREA ANALYSIS table or proposed setbacks
  existing_plan              — existing conditions plan, demolition plan, OR existing site plan (pre-works)
  proposed_plan_primary      — proposed GROUND FLOOR plan with room labels, dimensions, scale 1:100
  proposed_plan_ff           — proposed FIRST FLOOR (upper floor) plan in a multi-storey dwelling
  proposed_plan_supplementary — secondary context sheet (e.g. landscaping overlay, no room labels)
  rcp                        — Reflected Ceiling Plan or lighting layout
  roof_plan                  — roof plan only
  electrical_plan            — electrical / power / data plan
  elevations                 — external or internal elevations
  sections                   — building sections
  door_schedule              — door schedule table
  window_schedule            — window schedule table
  joinery_detail             — construction details, joinery elevations, and
                               selection/specification sheets tied to a specific
                               room or element named in the title (e.g. "KITCHEN
                               INTERNAL ELEVATIONS", "BATHROOM SELECTIONS",
                               "FENCING TO PROPERTY", "WINDOW SEAT DETAILS").
                               Use for any detail sheet named after a specific
                               element. Do NOT use for project-wide general
                               specification sheets — those belong in general_notes.
  shadow_diagram             — shadow / overshadowing diagrams
  perspective                — 3D renders or perspective views
  irrelevant                 — anything not fitting above

RULES:
- proposed_plan_primary is the GROUND FLOOR proposed plan (room labels, dimensions, scale 1:100).
  For single-storey sets there is exactly one. For multi-storey sets the ground floor is primary;
  use proposed_plan_ff for each upper-floor plan.
- proposed_plan_supplementary is for secondary sheets that lack room labels and full dimensions
  (e.g. a context or landscaping overlay). Do NOT use it for a floor plan with rooms.
- site_plan is the PROPOSED site plan — typically includes the AREA ANALYSIS table or proposed
  setbacks. An existing/pre-works site plan belongs in existing_plan, not site_plan.
- A page with "AREA ANALYSIS" table is always site_plan regardless of its title.
- A page whose title contains "WINDOW & DOOR SCHEDULE" (whether GF or FF) MUST be
  classified as door_schedule. window_schedule is ONLY for pages that are exclusively
  window schedules, not combined door-and-window schedules.
- A page whose title contains "Shadow" or "Shadows" (e.g. "Shadows - 9am", "Shadows - 3pm"), or whose
  drawing number is in the A800–A899 range, is shadow_diagram — NOT site_plan.
- The drawing number is found in the title block (bottom or right edge of the page), adjacent to the
  architect name, project name, date, and "Issue for Construction" text. Do NOT use section reference
  bubbles (e.g. "1 / A500" appearing mid-page in the drawing body) as the drawing number — those are
  cross-references to other sheets, not the identity of this page.
  While most drawing numbers follow the A### standard (e.g. A100, A201), some projects use
  page-number format like "05 of 47" or "Sheet 5". Use whatever unique identifier appears
  adjacent to the project name / architect / date in the title block.
- Return ONLY a JSON array. No markdown, no explanation, no wrapping text.

OUTPUT FORMAT — a JSON array of objects, one per page in input order:
[
  {
    "page_index": 0,
    "classification": "<class>",
    "drawing_no": "<e.g. A100 or null>",
    "scale": "<e.g. 1:100 or null>",
    "date": "<e.g. 13/07/20 or null>",
    "reasoning": "<one short sentence explaining the classification>"
  },
  ...
]
